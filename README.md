# ΟΑΧ — ειδοποιήσεις Telegram

Έλεγχος όλων των ημερών σε κυλιόμενο παράθυρο 7 ημερών, για 20:00, 21:00 και 22:00 (ώρα Ελλάδας). Το GitHub Actions εκτελεί τον έλεγχο περίπου κάθε 30 λεπτά. Η εκτέλεση μπορεί να καθυστερήσει ή να παραλειφθεί· δεν εγγυάται άμεση ειδοποίηση και ισχύουν τα όρια του λογαριασμού GitHub.

## Ρύθμιση

Στο Settings → Secrets and variables → Actions πρόσθεσε:

- OAX_USERNAME
- OAX_PASSWORD
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

Οι κωδικοί αποθηκεύονται μόνο στα Secrets, ποτέ στον κώδικα. Στο Telegram δημιούργησε bot με τον επίσημο @BotFather (/newbot), άνοιξε το bot σου και στείλε /start. Το chat ID βρίσκεται από το getUpdates του Telegram Bot API. Μην κοινοποιείς διευθύνσεις που περιέχουν το bot token.

Για δοκιμή σύνδεσης αρκούν τα δύο OAX Secrets. Actions → OAX alerts → Run workflow → Diagnostic only ενεργό. Η διαγνωστική εκτέλεση δεν στέλνει ειδοποιήσεις. Τα artifacts περιέχουν χαρακτηριστικά θέσεων, χωρίς ονόματα μελών, cookies ή κωδικούς. Σε αποτυχία αναγνώρισης παράγεται δομή HTML με αφαιρεμένα προσωπικά στοιχεία. Αλλαγές στο πρόγραμμα, τη ρύθμιση ή το workflow εκκινούν αυτόματα διαγνωστική δοκιμή.

## Αναγνώριση και ειδοποιήσεις

Η πραγματική σελίδα χρησιμοποιεί λίστες με τις στήλες ΓΗΠΕΔΟ 1–6. Ως διαθέσιμη αναγνωρίζεται μόνο θέση με άμεσο σύνδεσμο «Νέα Κράτηση». Κενά κελιά χωρίς αυτόν τον σύνδεσμο δεν θεωρούνται διαθέσιμα. Η δομή επιβεβαιώθηκε από διαγνωστικό αρχείο συνδεδεμένου λογαριασμού. Αλλαγές στη σελίδα μπορεί να απαιτήσουν προσαρμογή. Το πρόγραμμα δεν πατά συνδέσμους κράτησης και δεν κάνει κρατήσεις.

Οι προγραμματισμένες ειδοποιήσεις λειτουργούν μόλις υπάρχουν και τα Telegram Secrets. Χωρίς αυτά η εκτέλεση αναφέρει ότι οι ειδοποιήσεις είναι ανενεργές. Το state.json αποθηκεύει θέσεις που ήταν διαθέσιμες στον προηγούμενο έλεγχο. Ο πρώτος έλεγχος ειδοποιεί για τις ήδη διαθέσιμες θέσεις. Στη συνέχεια ειδοποιεί για νέες ή επανεμφανιζόμενες διαθέσιμες θέσεις. Κλείσιμο και επανάνοιγμα μεταξύ δύο ελέγχων δεν ανιχνεύεται. Αποτυχία αποθήκευσης κατάστασης μπορεί να προκαλέσει διπλές ειδοποιήσεις.

Το days_ahead στο config.json ορίζει το παράθυρο ημερών (1–31), εφόσον το ημερολόγιο επιτρέπει πρόσβαση σε αυτές. Οι προηγούμενες ώρες εξαιρούνται. Αποτυχία σύνδεσης ή μη αναγνωρίσιμη σελίδα είναι σφάλμα, όχι ένδειξη ότι δεν υπάρχει διαθεσιμότητα. Δεν παρακάμπτεται CAPTCHA ή δεύτερος παράγοντας.
